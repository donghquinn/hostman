지원 프로토콜

세 가지 프로토콜, 하나의 창

엔드포인트를 호출하고 상세한 네트워크 응답을 확인하며, 불필요한 부하 없이 로컬에서 API 요청을 체계적으로 관리하세요.

HTTP & REST

표준 웹 API

JSON, Form Data, 바이너리 업로드 및 GraphQL을 포함한 GET, POST, PUT, DELETE 요청을 자유롭게 실행합니다.

WebSocket

실시간 데이터 스트림

지속적인 연결을 유지하며 실시간 메시지, 라이브 피드, 이벤트 소켓 데이터를 주고받고 검증합니다.

gRPC

고성능 RPC 통신

별도의 코드 생성 없이 .proto 명세나 서버 리플렉션을 활용해 마이크로서비스 엔드포인트를 직접 테스트합니다.

빠르고 간결한 설계

API 테스트에 필요한 본질에만 집중했습니다.

많은 API 클라이언트가 거대한 클라우드 플랫폼으로 변해왔습니다. hostman은 로컬 환경에서 요청을 보내고 응답을 즉시 확인하는 본연의 목적으로 돌아갑니다.

즉각적인 실행

회원 가입이나 불필요한 의존성 설치가 필요 없습니다. 적은 디스크 용량으로 가볍게 동작합니다.

클라우드 추적 제로

로그인 화면도, 로깅 서버도 없습니다. 앱은 사용자가 지정한 엔드포인트와만 직접 통신합니다.

Git 친화적 저장 방식

컬렉션은 ~/.hostman/collections/ 경로에 가독성 높은 JSON 파일로 저장되어 버전 관리와 파일 공유가 용이합니다.

제한 없는 모든 기능

유료 등급, 요청 횟수 제한, 팀 인원 제약이 없습니다. 제공되는 모든 기능을 즉시 사용할 수 있습니다.

하나의 직관적인 인터페이스

HTTP, WebSocket, gRPC를 하나의 창에서 탭으로 전환하며 환경 변수와 요청 히스토리를 공유합니다.

상세한 네트워크 타임라인

DNS, TCP 연결, TLS 핸드셰이크, TTFB, 다운로드 시간 등 응답 단계별 지연 요소를 직관적으로 분석합니다.

명확한 기능 범위

의도적으로 제외한 기능들

  • —테스트 스크립트. 요청 전후 훅 실행이나 자동화된 검증 코드를 지원하지 않습니다.
  • —컬렉션 실행기. 요청은 개별적으로 직접 실행하며 자동화된 CI 배치 연동을 제공하지 않습니다.
  • —목 서버 및 모니터링. 호스팅 형태의 목 서버나 업타임 모니터링 같은 플랫폼 기능을 포함하지 않습니다.
  • —클라우드 협업. 별도의 클라우드 공유 대신 Standard Git 워크플로우와 로컬 파일 공유 방식을 권장합니다.
  • —자동 OAuth 2.0. 발급받은 Bearer 토큰이나 API 키를 인증 설정에 직접 입력하여 사용합니다.
  • —자동 쿠키 저장소. 응답 쿠키를 명확히 표시하지만 세션 간 자동으로 저장하거나 재전송하지 않습니다.
  • —동적 요청 체이닝. 필요한 토큰 및 변수는 수동으로 복사하거나 환경 변수를 활용합니다.
  • —코드 조각 생성. 인터페이스의 간결함을 위해 실행 기능 자체에만 집중합니다.
설계 철학

자동화된 CI 테스트, 클라우드 워크스페이스, 복잡한 인증 절차가 필수적이라면 Postman이나 Bruno와 같은 도구가 더 적합할 수 있습니다.

hostman은 불필요한 오버헤드 없이 빠르게 요청을 보내고 검증하는 수동 테스트 작업에 최적화되어 있습니다.

비교

hostman의 위치

hostman은 로컬 환경에서 HTTP, WebSocket, gRPC 요청을 안정적으로 실행하고 기록하는 데 집중된 경량 클라이언트입니다.

도구범위계정저장 방식
hostman HTTP + WebSocket + gRPC (핵심 테스트 기능 집중) 없음, 영구히 디스크의 일반 JSON 파일
Postman 전체 API 플랫폼 (목 서버, 문서화, CI 파이프라인) 필수 (클라우드 동기화) 독자적인 클라우드 저장소
Bruno HTTP 중심 데스크톱 클라이언트 없음 일반 파일 (Git 친화적)
Insomnia API 클라이언트 및 설계 플랫폼 점진적 계정 필수화 독자적인 클라우드 동기화
curl / HTTPie CLI 기반 도구, 스크립트 전용 없음 사용자 스크립트
Paw / RapidAPI 네이티브 Mac API 클라이언트 없음 유료 라이선스
