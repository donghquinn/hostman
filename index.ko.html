무엇을 하는 도구인가

세 가지 프로토콜, 하나의 창

누군가 API를 알려줬다면, hostman로 그 API를 호출하고 돌아온 내용을 그대로 확인하고, 쓸 만한 요청은 저장해 두었다가 나중에 다시 찾아 쓸 수 있습니다.

HTTP

가장 흔한 방식

웹으로 데이터를 주고받습니다. GET, POST, PUT, PATCH, DELETE 등을 지원하고 JSON·폼·파일 업로드·GraphQL 본문을 보낼 수 있습니다.

WebSocket

연결이 열려 있는 방식

연결을 열어 둔 채 메시지가 계속 들어옵니다 — 실시간 시세, 채팅, 알림 등.

gRPC

서버 간 통신

주로 회사 내부 서버끼리 쓰는 더 빠른 형식. 서버가 스스로 알려주는 정보나 .proto 파일로 동작하며, 코드 생성이 필요 없습니다.

postman을 두고 왜 이걸 쓰나

API 클라이언트를 여는 이유는 대개 하나입니다

요청을 보내고 응답을 보는 것. 그게 전부라면 큰 소프트웨어를 켜서 그중 일부만 쓰고 있는 셈입니다. hostman는 거기서 그 일부만 남긴 것입니다.

미리 설치할 것이 없습니다

회원 가입도, 계정도 없이 앱 하나뿐입니다. 디스크는 200 MB 이하.

계정이 아예 없습니다

로그인 화면이 없습니다. 로그인할 서버 자체가 없기 때문입니다. 앱은 여러분이 지정한 서버하고만 통신합니다.

그냥 파일입니다

컬렉션은 ~/.hostman/collections/에 읽을 수 있는 JSON으로 저장됩니다. Git에 넣고, diff로 보고, 첨부 파일로 보낼 수 있습니다.

유료 기능 뒤에 숨은 것이 없습니다

유료 등급도, 요청 개수 제한도, 인원 수 제한도 없습니다. 보이는 것이 전부입니다.

세 가지가 한곳에

HTTP, WebSocket, gRPC가 한 창의 세 탭으로, 변수와 컬렉션과 히스토리를 함께 씁니다.

느릴 때 답이 되는 정보

모든 응답을 DNS, 연결, TLS 핸드셰이크, 첫 바이트까지 시간, 다운로드로 나눠 보여 줍니다. TLS 버전, 암호 방식, 인증서 만료일도 함께.

404 찾을 수 없음

일부러 넣지 않은 기능

  • —테스트 스크립트. 요청 전후에 실행되는 코드도, 성공/실패 판정도 없습니다.
  • —컬렉션 실행기. 요청은 하나씩 직접 보냅니다 — CI 연동도 없습니다.
  • —목 서버, 모니터, 문서. 요청 자체를 둘러싼 플랫폼 기능은 없습니다.
  • —팀 협업. 공유는 파일을 보내는 방식입니다.
  • —OAuth 2.0 흐름. Bearer, Basic, API 키는 지원합니다. 토큰은 다른 곳에서 발급받아 붙여 넣으세요.
  • —쿠키 저장소. 쿠키는 보여 주기만 하고, 저장하거나 자동으로 다시 보내지 않습니다.
  • —요청 자동 연결. 토큰은 직접 복사해 환경 변수에 넣어야 합니다.
  • —코드 생성. curl 명령이나 코드 조각을 만들어 주지 않습니다.
솔직한 말

이 도구가 내 일에 맞는지 1분 안에 판단할 수 있도록 솔직하게 적었습니다. 위 항목 중 하나라도 필요하다면 hostman는 맞지 않는 도구이며, Postman이나 Bruno가 더 나을 것입니다.

Windows와 Linux 빌드는 아직 macOS만큼 검증되지 않았습니다. hostman는 애플 공증도 받지 않아 macOS에서 처음 실행할 때 경고가 뜨는데, 이는 유료 프로그램을 거치지 않은 모든 앱에 나타나는 현상일 뿐입니다.

비교

hostman가 있는 자리

hostman의 자리는 일부러 좁게 잡았습니다. HTTP, WebSocket, gRPC 요청을 제대로 보내고 그 답을 기억하는, 가능한 한 작은 도구입니다.

도구범위계정저장 방식
hostman HTTP + WebSocket + gRPC, 의도적으로 좁은 범위 없음, 영구히 디스크의 일반 JSON 파일
Postman 목 서버·모니터·문서·팀 워크스페이스까지 전부 필수, 클라우드 동기화 독자 형식, 동기화됨
Bruno HTTP 중심, 철학이 가장 비슷함 없음 일반 파일, Git 친화적
Insomnia Postman과 비슷한 범위 점점 계정 쪽으로 독자 형식, 동기화됨
curl / HTTPie 스크립트에 강함, 화면 없음 없음 스크립트하기 나름
Paw / RapidAPI 네이티브 Mac 앱, 완성도 높음 없음 유료
